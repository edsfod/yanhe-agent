# Setup

uv provides Python and all the dependencies, ffmpeg among them. If the shell has no `uv`, or `uv run` fails while it downloads Python or the dependencies, tell the user that the setup script next to `yanhe_agent.py` installs uv into `~/.local/bin`, puts that folder on PATH and downloads Python and the dependencies, and run it once they agree: `powershell -NoProfile -ExecutionPolicy Bypass -File <scripts>/setup.ps1` on Windows, from any shell, or `sh <scripts>/setup.sh` on macOS and Linux, writing `<scripts>` as an absolute path. Wait for it to finish, which may take a few minutes; it downloads nothing from the courses. It first tests whether the official sources or the Chinese mirrors are faster, uses the faster and falls back on the other, and prints where uv is; use that path instead of `uv` until the harness is restarted.

If it fails, show the user its last lines and stop. Do not try other download sites, proxies, unofficial builds, turning off certificate checks, `sudo`, `--break-system-packages` or changes to system settings. In a sandbox without network access, run it again with network access. Run the scripts through uv, not through some Python or environment found elsewhere on the machine; the only replacement for `uv run` is a Python 3.11+ virtual environment the user made with the dependencies the script declares.
